# Composer and references implementation plan

**Goal:** Enter sends, Shift+Enter inserts a newline, and creators can submit links and real file/image references through the chat composer. Keep the existing local app and personal subscription model.

**Scope:** A small attachment tray, paste/drag/drop/file picker, actual bounded source extraction, project retention/backup, grounded AI use, and an explicit retry action. No knowledge-base service, hosted storage, desktop automation, KKY platform access or silent provider/model switching.

## Contracts

- Enter sends only when not composing IME text and Shift is not held. Shift+Enter remains a newline. Empty messages do not send; attachment-only input may send a clearly labeled reference message. Typing while a reply is pending stays saved and cannot double-submit.
- POST `/api/references` accepts `{files:[{name,mimeType,data:base64}],links:[url]}` and returns `{references:[...]}`. Maximum5 sources, files3MiB each/6MiB total, PNG/JPEG512KiB each/max2 images. Reference ingestion request cap9MiB; ordinary JSON request cap4MB.
- `referenceSchema` in `src/references.js`: `{id,name,kind:'file'|'link'|'image',mimeType,text,status:'ready'|'excerpt'|'unavailable',note,url?,imageData?}`. Strings bounded; max16000 extracted characters per source and60000 total. Images are validated data URLs. Unknown formats, scanned PDFs and inaccessible pages are explicitly unavailable rather than supposedly read. Never execute macros/scripts or recalculate spreadsheet formulas.
- `prepareReferences(raw)` performs actual extraction and public-link reads. Plain text/Markdown/CSV/TSV/JSON, PDF, DOCX, PPTX and XLSX text are supported; PNG/JPEG become actual model image inputs. New PDF dependency may be exact-pinned `unpdf`; no external Python/system installation. Parsing/ZIP/PDF work is bounded and cancellable outside the HTTP event loop. Link reads reject private/local/link-local addresses on initial request and redirects, pin resolved public IPs, limit size/time, and do not use account cookies.
- Project state stores processed `references` and unsent `pendingReferences` only (no original PDF/Office binary). `pendingReferenceInputs`/file reading may be UI-local but status survives when processed. Submitted reference names/URLs appear with the human message. Processed references persist in the project backup, not the preference profile or sale package. Backup limit8MB with clear recovery error.
- POST `/api/interview` adds `references: referenceSchema[]`, max5. Bounded extracted text is prompt source data, never workflow instructions or automatic creator biography. Known reference quotes may ground suggestions but never establish the creator's credentials/results. New preference evidence remains actual typed creator input only.
- Requests explicitly supply `currentInput` with the original typed creator text; synthetic workflow requests use an empty string. Human message source labels may be retained for display, but file names and reference content cannot become preference evidence. Retry reuses that same original typed text with the currently selected model, without duplicating the human message.
- Provider `infer(...,{...,images:[{name,mimeType,data:base64}]})` handles at most2 validated PNG/JPEG images with actual native multimodal input. Codex uses official `--image` paths to generated safe files in its existing ephemeral owned workspace. Claude uses a supported documented headless image route, preserving tool/config/process isolation. Unsupported provider capabilities must produce a truthful specific error, not fake text-only vision. No API billing or token handling.
- Server serves an explicit new `/composer.js` browser module, wires ingestion with larger route-specific body limit, and retains local Host/Origin rules. Root owns server/docs/package version after parser dependency handoff and Git/publication.

## Tasks and ownership

1. Intake worker owns src/references.js, src/reference-worker.js, test/references.test.js and exact PDF dependency package.json/lock changes. Prove extraction, unavailable/scanned files, ZIP/input/time bounds and public-link protections. Publish contract to peers early.
2. AI worker owns src/interview.js/providers.js and test/reference-harness.test.js. Prove bounded reference context, source/creator distinction, actual image argv/stdin/bytes, cleanup and unchanged model/process isolation. Read official current CLI image docs/help first. No live provider call until root handoff.
3. Composer worker owns public/app.js/index.html/studio-store.js, new public/composer.js and focused tests. Prove keyboard behavior, file/link/clipboard/drop flow, queued/removable references, persistence, source status and explicit retry using retained original message/current chosen model. No changes to product-preview/export design.
4. Root writes focused failing HTTP tests, integrates ingestion/static route/body limits, performs one combined test and one independent exact-head review, then verifies Enter + a real reference-assisted reply in an isolated browser before restarting the usual local app. Preserve the user's project and unsent work. Publish to the existing public repo, refresh ZIP, report actual supported formats/limits.
