# Lato font provenance

Regular and bold font bytes are retrieved by `scripts/prepare-fonts.js` from Google Fonts commit `f3b885d5590e307e02542f1a724cec55d567fdaa`, paths `ofl/lato/Lato-Regular.ttf` and `ofl/lato/Lato-Bold.ttf`.

- Lato-Regular.ttf SHA-256: d636e4683231f931eda222d588e944d082bfd3bdba02f928bee461c0f185b251
- Lato-Bold.ttf SHA-256: 8a0aace75d33794eece4b28187bfc1df0bbd2888b5d8a56e01788c8d65d16be1
- License: SIL Open Font License 1.1, preserved in OFL.txt.

The source fonts are unmodified. SVG previews package their same tables as compressed WOFF in memory. PDF embeds glyph subsets. Editable Word and PowerPoint reference the Lato family, so a receiving editor may substitute another font if Lato is unavailable. Native Office and Canva import are separate from successful local file creation.
