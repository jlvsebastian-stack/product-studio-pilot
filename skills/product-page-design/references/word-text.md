# Editable Word and text

Word is a substantive editable reading document. Preserve headings, paragraphs, ordered actions, checklist items, code text, source URLs and the creator's language. Use semantic Word headings and a clear cover, with readable A4 margins and page numbers. Do not replace the manuscript with images of designed pages or an outline. Word may paginate differently from the fixed SVG/PDF/PPTX pages.

The full-product Markdown download preserves the original manuscript bytes. A draft-sample Markdown download adds the review status label before the otherwise unchanged manuscript. The project JSON checkpoint retains the brief and any explicitly uploaded cover image, with no browser preference profile. The optional listing download contains only the creator's provided or approved listing copy. Label illustrative examples and proposed commercial terms honestly.

The local exporter creates real DOCX and PPTX packages. Package text checks establish editable content, not native Office or Canva rendering. Render exported files through a supported headless renderer when available. Otherwise report native rendering UNRUN rather than calling a package inspection visual proof.
