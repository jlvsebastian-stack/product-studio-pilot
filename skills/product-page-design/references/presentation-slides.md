# Presentation slides

For a presentation, slide deck, slides or webinar, write one useful teaching beat per main section. Use a specific heading, concise complete teaching copy, and a real example or activity where it helps. A webinar includes the actual presentation and presenter notes by default; a script alone is insufficient. Keep the accumulated slide manuscript complete.

Use one `## Slide title` section per slide. Write the audience-facing content first, followed by `### Presenter notes` and the notes for that slide. Notes provide the explanation, demonstration instructions, audience prompts and transition as needed. Keep explanations that belong to the presenter in the explicitly labeled notes; do not arbitrarily move approved on-slide content into notes to reduce slide count.

The local exporter detects presentation, slide, deck and webinar format labels and uses landscape 16:9 geometry for SVG preview, PDF and PPTX. Presenter notes are separate from the visible slide canvas and PDF, stored with the corresponding PPTX slide as native speaker notes, and retained in editable Word/Markdown source. Visible content continues onto additional slides when needed, with the section title retained. To create shorter slides, revise the manuscript with the creator's approval. Do not promise that another editor's import preserves notes without checking that import.

Use ordered steps for sequence diagrams. Use an actual worked case for an example layout. Do not add fabricated numbers or charts. Native PPTX text, rules, circles and checkboxes remain editable. A creator-supplied photo is a raster image, with its aspect ratio preserved. The PPTX uses Lato font names; install the supplied licensed font source if the receiving editor substitutes it. Canva import and native PowerPoint rendering require their own verification.
