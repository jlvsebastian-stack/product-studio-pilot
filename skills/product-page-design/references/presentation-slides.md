# Presentation slides

For a presentation, slide deck or slides, write one useful teaching beat per main section. Use a specific heading, short complete teaching copy, and a real example or activity where it helps. Keep the accumulated slide manuscript complete. Speaker or facilitator notes must be clearly labeled if the creator requests them.

The local exporter detects presentation, slide or deck format labels and uses landscape 16:9 geometry for SVG preview, PDF and PPTX. Content continues onto additional slides when needed, with the section title retained. It never discards source paragraphs or hides them in notes to achieve an arbitrary slide count. To create shorter slides, revise the manuscript with the creator's approval.

Use ordered steps for sequence diagrams. Use an actual worked case for an example layout. Do not add fabricated numbers or charts. Native PPTX text, rules, circles and checkboxes remain editable. A creator-supplied photo is a raster image, with its aspect ratio preserved. The PPTX uses Lato font names; install the supplied licensed font source if the receiving editor substitutes it. Canva import and native PowerPoint rendering require their own verification.
