# Try Kaya Ko Yan! Digital Product Creator

Send a local-capable AI assistant:

> Install https://github.com/jlvsebastian-stack/product-studio-pilot on my computer and open Product Studio.

Next time, say **Launch Product Studio**. Use ChatGPT desktop local Work, local Codex, or Claude Code; a normal website chat with no local tools cannot install computer software.

Choose your own AI account in the local app. Give a vague expertise answer first, then check that it asks a useful follow-up and uses your real example. Approve only a direction that is accurate. Save/reopen a project, edit a paragraph and check the actual PDF/text files. Canva and Workspace are optional.

For this pilot, also try these small checks:

1. State a real style preference, such as “Use plain English and short steps.” Check My preferences. An inferred preference should ask for confirmation before it is remembered. Edit or forget it, then start another project and check the result.
2. Start a new project while an answer is unsent; reopen the earlier project and confirm it is retained. Save project downloads your portable backup; local autosave stays in this browser.
3. Check the selected model and quality. If your account cannot use a model, choose another explicitly. The app should explain the failure rather than switch silently.
4. Approve one designed sample before expanding. Ask for a correction, inspect the change and try restoring the previous approved version. Read the final exported pages, not just the in-app preview.
5. Inspect the illustrative product if you want to see a complete output first. It is a demonstration, not your expertise or proof of customer results. At completion, inspect companion suggestions and listing copy before choosing anything extra.

Report your operating system, AI provider, any installation friction, questions that felt generic and whether saving/files worked. Only share the interview details you choose. A Canva-compatible file or spreadsheet specification is different from a verified native design or working Sheet.
