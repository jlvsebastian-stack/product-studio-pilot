# Try Product Studio privately

You need your own ChatGPT account with permission to add a custom MCP server. Use ChatGPT on the web for the first test. The person inviting you will send the private connection URL separately. Do not post that URL publicly.

1. Open [ChatGPT Plugins](https://chatgpt.com/plugins). Use the plus button and choose **Add custom MCP server**. If your account shows the older Apps or developer-mode interface, find the custom MCP connection option there. Account and workspace controls may hide or prevent it.
2. Name it **Product Studio Pilot** and paste the full private HTTPS invite URL. Choose **No authentication / None**: the unguessable invite URL is the pilot's access mechanism, rather than a separate OAuth sign-in. Review the host's warning and tool list, then create/install the custom plugin.
3. Start a new chat, type `@`, and select **Product Studio Pilot**. Send: **“Help me create a useful digital product from my own knowledge. Start by interviewing me. Ask one question at a time.”**
4. Answer from your actual experience. The interviewer should ask for real decisions, examples, mistakes, and exceptions. Tell it when a suggestion feels generic or inaccurate. The brief appears in the panel; the conversation stays in ChatGPT.
5. Advance only when the direction is right. Choose the product format after defining the audience and offer. Build and refine the actual content one section at a time.
6. In **Manuscript**, edit any wording you want and use **Share my edits with ChatGPT**. In **Downloads**, review the manuscript, confirm the review, and prepare the files. Download the PDF, editable Word, and Canva-compatible PowerPoint. Import the PowerPoint into Canva yourself and check its text and layout.
7. Use **Save checkpoint** before stopping. To resume in another chat, open Product Studio, then **Open checkpoint** and continue the conversation.

If custom MCP connections or host downloads are unavailable on your account, report the exact limitation to the person running the pilot. Do not share your password or buy an API key for this test. Claude support has not yet been accepted for this release.

For the first short test, check whether the interviewer asks a useful follow-up to a vague answer, remembers a specific detail you gave, and avoids inventing your experience. Then test one actual section and its editable downloads. A full twelve-stage creator journey is a separate acceptance test.

Report where it felt generic, what it misunderstood, which actual question helped, whether your edits survived, and whether the files opened correctly. Share only the material you choose; the pilot operator does not have a project dashboard containing everyone's interviews.

The current connection procedure is based on [OpenAI's custom MCP setup documentation](https://developers.openai.com/plugins/deploy/connect-chatgpt). UI names and account availability can change.
